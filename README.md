# Hospital Emergency Room Analytics Dashboard (Power BI)

##  Project Overview
This project is a Power BI dashboard created as part of my learning journey in data analytics. 
The dashboard analyzes hospital emergency room operations to understand patient flow, wait times, admissions, referrals, and demographic patterns.

##  Key Insights
- Total patients analyzed: 9,216
- Average patient wait time: 35.3 minutes
- Patient satisfaction score: 4.99
- Admission vs non-admission trends
- Department-wise referral analysis
- Peak hours and busy days identification
- Demographic analysis (age, gender, race)

##  Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization & Dashboard Design

##  Project Structure
- `/images` → Dashboard screenshots
- `/data` → Dataset used for analysis 

##  Learning Outcome
This project helped me strengthen my skills in data cleaning, KPI creation, DAX calculations, and interactive dashboard development using Power BI.
